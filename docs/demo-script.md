# Five-minute demo script

1. Open the app as Steve Student and point out the two support-request cards.
2. Switch to Morgan Mentor and claim "Practice related-rates problems."
3. Add a public note offering a Thursday afternoon study session.
4. Add a staff note about the mentor handoff plan.
5. Switch back to Steve and show that the public note appears.
6. Explain verbally that staff notes are private.

If the data is not in its initial state, run `npm run reset:data` and restart
the server. The demo sequence is presentation guidance, not a product rule or
automated acceptance test.
