# Roadmap ideas

This list captures possibilities, not commitments. It is not a source of
current product behavior.

- Calendar view for mentor office hours
- Email digests
- Multiple tutoring programs
- Saved filters
- Course-section import
- Request templates
- Optional mentor subject badges
- Import from a spreadsheet
- An anonymized aggregate-impact page

The maintainers revisit this list after each pilot. Do not implement an item
unless a current work item has acceptance criteria for it.
