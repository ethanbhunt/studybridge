# UI copy notes

Use plain, encouraging language. Prefer "support request" to "ticket" in
anything students see, although internal type names still use `Request`. Say "claim" rather than
"take ownership" and "staff note" rather than "internal comment."

Empty-state copy should explain the current filter: "No open requests" is more
useful than "Nothing here." Buttons use sentence case and no terminal period.

The project name is always one word: StudyBridge. The bridge symbol in the
header is decorative and must have an empty accessibility label.
